# karikounkel.com — the marble jar

**The single source of truth for Kari's front door.** Edit, commit, push — karikounkel.com updates itself in ~1 minute (no DreamHost upload).

- `marbles.js` — the product list (edit this to add/change/remove a marble)
- `app.js` — the design + behavior
- `jar.png` — the jar
- `index.html` — the shell (also lives on DreamHost; it just loads the two files from GitHub Pages)

karikounkel.com (DreamHost) serves the shell; the shell loads everything from this repo via GitHub Pages. DNS is never touched, so Kari's Google email stays safe.
